# 🔮 Descubra seu Signo

Projeto em PHP + XML + Bootstrap que identifica o signo com base na data de nascimento do usuário.

## ✨ Funcionalidades

- Formulário com validação de data
- Consulta de signo usando XML
- Exibição de ícone, descrição, elemento, planeta e cor do signo
- Layout moderno e responsivo

## 📁 Estrutura

- `index.php` – Página de entrada
- `show_zodiac_sign.php` – Resultado do signo
- `signos.xml` – Base de dados com os 12 signos
- `assets/css/style.css` – Estilização
- `layouts/header.php` – Inclusão do Bootstrap

## 🛠 Requisitos

- PHP 7+
- XAMPP ou servidor Apache local
